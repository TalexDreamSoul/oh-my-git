# Git 可视化学习游戏

面向中文学习者的新版本 Git 教学项目，用可视化和互动关卡讲清 commit、branch、merge、remote 等核心概念。

## 说明

- 新版本以 Web 访问和在线分享为主。
- 项目受到原 **Oh My Git!** 交互式学习方向的启发。
- 本项目与原 **Oh My Git!** 没有组织、维护、发布、品牌、赞助或支持关系。
- 仓库中的 Issue、PR、Release、部署和路线图只服务于本项目。

## 部署

新版本可以直接部署到 Cloudflare Pages（CF）：导入仓库，选择默认分支作为生产分支，按项目配置或 Cloudflare 自动识别完成构建即可。

## Godot 汉化分支

如需查看或维护旧版 Godot 汉化内容，请切换到 `godot` 分支。当前主分支以新版本为主。

## 贡献

欢迎提交 Issue 或 Pull Request，重点包括学习路径、关卡设计、中文文案、交互反馈、Web 体验和部署配置。

请不要把本项目的问题提交到原 Oh My Git! 项目；本仓库独立处理自己的维护事项。
